# Pixel Foundry

Create icons, avatars, or game assets on a small fixed grid. The starter artwork is an original diving helmet.

## Run

From the repository root, run `npm start` and open **Pixel Foundry** in the catalog. The editor saves your draft through the host’s workspace storage.

## Use the app

Pick an ink color or eyedropper and draw with Pencil, Line, Rectangle, Filled Rectangle, Ellipse, or Flood fill. Enable horizontal or 4-way symmetry, nudge, flip, or rotate 90°, undo/redo up to 50 strokes, and export transparent PNG, crisp SVG, or JSON projects.

## Scope

The grid is 24 × 24. PNGs contain the drawing with transparency. History resets when the page reloads.

## Build a product

Add multi-size canvases and a versioned customer asset library for a brand icon service.

Use `npm run fork -- pixel-foundry <destination>` from the catalog root to extract this app with its runtime and license.
