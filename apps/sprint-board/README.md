# Sprint Board

Run a small delivery team with a visual task board, explicit work limits, and blocker tracking.

## Use the app

Create a task, assign points and move it from backlog into the sprint. Select a card to view acceptance notes, log a blocker, or move it between lanes. Clear the blocker before marking the task done.

## Data and calculations

All non-backlog points form the sprint commitment. Doing allows three tasks and Review allows two to surface bottlenecks. Stage and blocker changes append dated entries. Each workspace represents one sprint and stores its board locally.

## Build on it

Add sprint snapshots and team-configurable work limits, then connect issue tracking and authentication for a hosted delivery board.
