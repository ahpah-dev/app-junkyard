# Quote Foundry

Build client estimates from itemized services, apply discounts and tax, and export a customer-ready quotation.

## Use the app

Create a quote, enter its recipient and itemized services, then review the total in the register. Open it to download a plain-text quotation or styled HTML proposal with signature lines, mark it Accepted, or clone an existing quote into a new draft.

## Data and calculations

Each price is stored in integer USD cents. The discount applies to the subtotal and tax applies to the discounted amount. Both adjustments round to the nearest cent. The open pipeline counts unexpired draft and sent quotes. Tax rates and terms are supplied by the operator.

## Build on it

Add a seller profile and a PDF renderer to sell branded proposals. Introduce approval history and client acceptance links when connecting a server.
