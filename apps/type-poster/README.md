# Type Poster

Lay out a poster for an event or studio announcement. All elements are original text and vector geometry.

## Run

From the repository root, run `npm start` and open **Type Poster** in the catalog. The editor saves your draft through the host’s workspace storage.

## Use the app

Edit the top line, headline, and footer, or start from a curated preset. Add line breaks to direct the headline layout. Choose a format, one of six compositions (Orbit, Steps, Band, Swiss Grid, Radial Burst, Constructivist), and a type family. Adjust ink, paper, and accent with live WCAG contrast feedback, then export SVG, 2× PNG, or JSON project files.

## Scope

Fonts resolve to system serif, sans, or monospace families. The SVG retains live text and may measure differently on another system. The editor supports solid colors.

## Build a product

Offer brand kits, hosted font support, custom templates, and campaign-size batch exports.

Use `npm run fork -- type-poster <destination>` from the catalog root to extract this app with its runtime and license.
