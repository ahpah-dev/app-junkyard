# Retainer Book

Compare tracked work against monthly client retainers and calculate billable overage.

## Use the app

Create a service month for a client. Enter the included hours, fee and overage rate. Open the retainer to log tasks, view projected month-end burn pace and effective hourly yield, or download an itemized time statement. The top metrics summarize the current month and CSV/JSON exports include the detailed timesheet.

## Data and calculations

Each retainer represents one client and calendar month. Logged minutes above the allowance accrue overage at the hourly rate, rounded once to USD cents. The estimate combines the monthly fee and overage. Unused time expires with the month.

## Build on it

Add a time-tracking integration and a client portal. Store time approvals and recurring retainer templates server-side before using it for team billing.
