# Incident Journal

Coordinate service incidents with timestamped updates, response milestones, and a reusable incident report.

## Use the app

Open an incident with detection time, severity, impact and lead. Open the record and append timestamped updates as the response progresses. Resolve it, reopen it if needed, and download the incident report.

## Data and calculations

All timestamps are UTC to the minute. The first logged update counts as acknowledgment. Resolution time runs from original detection through the latest resolution, including a reopening. Mean time to resolution uses currently resolved incidents.

## Build on it

Add webhook intake, status-page publishing and server-side audit history. Connect the response lead to an on-call directory and store each organization’s severity definitions.
