# Pipeline Ledger

Manage sales opportunities, forecast weighted revenue, and queue the next customer follow-up.

## Use the app

Create an opportunity with an owner, estimated value and probability. Set its next action and follow-up date. Inspect the stage and monthly close forecast charts, check overall win rate, use the Follow-up due filter for outreach, log conversations, or advance stages in one click. Export CSV or JSON snapshots anytime.

## Data and calculations

Open forecasts multiply the deal value in USD cents by its probability and round to cents. Won deals have their full forecast value and lost deals have zero. Stage changes and contact notes appear in each deal’s history.

## Build on it

Add team assignment rules, CRM synchronization, organization-level permissions and cohort reporting for a vertical sales product.
