# Pattern Press

Prototype repeating surface patterns and take a vector master into your design workflow.

## Run

From the repository root, run `npm start` and open **Pattern Press** in the catalog. The editor saves your draft through the host’s workspace storage.

## Use the app

Pick from six geometric motifs (quarter circles, cut diamonds, cross weave, Truchet arcs, hex lattice, Bauhaus blocks), symmetry mode (stochastic, 4-quadrant mirror, 4-fold rotational), paper color, and two inks. Set cells per tile and primary ink share, inspect the repeat preview, and export SVG, 1024px PNG, or CSS background rules.

## Scope

One repeat contains 2–8 cells on each axis. Artwork uses sRGB colors and SVG units. Print separation and press profiles are outside this starter.

## Build a product

Build a licensed pattern marketplace with shared seasonal libraries and physical swatch ordering.

Use `npm run fork -- pattern-press <destination>` from the catalog root to extract this app with its runtime and license.
